# 学术语言润色自检清单（逐项打钩）

## 改得对（机制 M）
- [ ] 改动都是真实语法/句法/搭配/标点/用词错误或必要一致性调整
- [ ] 未用换说法掩盖错误，未过度同义替换
- [ ] 未引入新的语法/搭配错误

## 说得像（机制 P）
- [ ] 术语全篇统一（中英文写法、缩写首次出现、大小写/连字符）
- [ ] 处理了同义混用与跨章节漂移
- [ ] 语气符合目标文体，无口语化/宣传化/绝对化/人称误用
- [ ] 读起来仍像同行写的学术文本

## 没改坏（机制 S）
- [ ] 原意、限定词强度保持不变（未偷偷加强/削弱结论）
- [ ] 因果与相关未被互换，否定范围未变
- [ ] 条件句、量词保持不变
- [ ] 数据、单位、引用编号、图表指向保持不变
- [ ] 术语译法与事实底稿一致
- [ ] 重复润色结论不漂移（以首次语义指纹为准）

## 讲得清（机制 L）
- [ ] 每处修改有原文、改文、修改类型、理由
- [ ] 修改类型取自受控类型（grammar/terminology/register/semantic_preservation/punctuation）
- [ ] invariant_safe 已标注，第三方可判断该不该改

## 结构与边界
- [ ] 交付"润色后完整文本 + 逐句对照表"，非单纯建议或整段重写
- [ ] 术语冲突/语义模糊进 human_review_items
- [ ] status 诚实（success/partial/blocked）
- [ ] 材料缺失/无法判断/运行失败分别说明
- [ ] 未编造事实、数据与 benchmark 分数
- [ ] 改写与审校分离完成，所有回退有 change_log
